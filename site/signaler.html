Signaler un problème

Remplissez ce qui vous paraît utile, puis le bouton ouvre GitHub avec le rapport déjà écrit.

  1. Fermez Erable, pour que le journal soit complet.
  2. Remplissez le formulaire et cliquez sur Continuer sur GitHub.
  3. Sur GitHub (connecté à votre compte), glissez le fichier eden_log.txt du dossier %APPDATA%\erable\log dans la description, puis cliquez sur Create.

N'écrivez ni mot de passe ni information personnelle : le rapport est public sur GitHub. Pas de compte GitHub ? En créer un est gratuit.
