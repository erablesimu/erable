1Où sont vos sauvegardes

  1. Dans la bibliothèque, faites un clic droit sur le jeu → Ouvrir l'emplacement des données de sauvegarde.
  2. Le dossier qui s'ouvre contient toute la sauvegarde de ce jeu pour le profil choisi.

Toutes les sauvegardes sont rangées dans %APPDATA%\erable\nand\user\save, un dossier par profil, puis un dossier par jeu.

Chaque profil a ses propres sauvegardes. Changer de profil n'en efface aucune.

2Faire une copie de sécurité

  1. Fermez le jeu.
  2. En haut à gauche : Outils → Gestionnaire de données, partie Sauvegardes.
  3. Cliquez sur le bouton d'export (infobulle « Exporter toutes les données de ce répertoire ») et choisissez où enregistrer le fichier .zip.
Gardez ce zip sur une clé USB ou un autre disque : il contient les sauvegardes de tous vos jeux et de tous vos profils.

3Les remettre, sur ce PC ou un autre

  1. Installez Erable et lancez une fois le jeu, puis fermez-le.
  2. Outils → Gestionnaire de données, partie Sauvegardes : bouton d'import (infobulle « Importer les données dans ce répertoire »), puis choisissez votre zip.
L'import remplace toutes les sauvegardes déjà présentes. Pour ne remettre qu'un seul jeu, copiez plutôt son dossier (étape 1) à la même place sur l'autre PC.

4Reprendre celles d'un autre émulateur

  1. Fermez l'autre émulateur (Eden, Lichii…).
  2. Au premier lancement, Erable propose d'importer son profil : choisissez-le et gardez Copier, qui laisse l'original intact.
  3. Sinon, copiez à la main le dossier du jeu depuis le dossier nand\user\save de l'autre émulateur vers celui d'Erable (étape 1).

1Where your saves are

  1. In the library, right-click the game → Open Save Data Location.
  2. The folder that opens holds this game's whole save for the chosen profile.

All saves live in %APPDATA%\erable\nand\user\save: one folder per profile, then one per game.

Each profile has its own saves. Switching profiles deletes none.

2Make a backup

  1. Close the game.
  2. Top left: Tools → Data Manager, Saves section.
  3. Click the export button (tooltip "Export all data in this directory") and choose where to save the .zip.
Keep that zip on a USB stick or another drive: it holds the saves of all your games and profiles.

3Put them back, on this PC or another

  1. Install Erable and start the game once, then close it.
  2. Tools → Data Manager, Saves section: the import button (tooltip "Import data for this directory"), then choose your zip.
Importing replaces all the saves already there. To bring back a single game, copy its folder (step 1) to the same place on the other PC instead.

4Take them from another emulator

  1. Close the other emulator (Eden, Lichii…).
  2. On its first start, Erable offers to import its profile: pick it and keep Copy, which leaves the original untouched.
  3. Otherwise copy the game's folder by hand from the other emulator's nand\user\save folder to Erable's (step 1).

1Wo deine Spielstände liegen

  1. In der Bibliothek: Rechtsklick auf das Spiel → Open Save Data Location.
  2. Der Ordner, der sich öffnet, enthält den ganzen Spielstand dieses Spiels für das gewählte Profil.

Alle Spielstände liegen in %APPDATA%\erable\nand\user\save: ein Ordner pro Profil, darin einer pro Spiel.

Jedes Profil hat seine eigenen Spielstände. Ein Profilwechsel löscht keinen.

2Eine Sicherung anlegen

  1. Schließe das Spiel.
  2. Oben links: Tools → Data Manager, Bereich Saves.
  3. Klicke auf die Export-Schaltfläche (Tooltip „Export all data in this directory“) und wähle, wo die .zip gespeichert wird.
Bewahre diese Zip auf einem USB-Stick oder einer anderen Platte auf: Sie enthält die Spielstände aller Spiele und Profile.

3Wiederherstellen, auf diesem oder einem anderen PC

  1. Installiere Erable, starte das Spiel einmal und schließe es wieder.
  2. Tools → Data Manager, Bereich Saves: die Import-Schaltfläche (Tooltip „Import data for this directory“), dann deine Zip wählen.
Der Import ersetzt alle vorhandenen Spielstände. Für ein einzelnes Spiel kopiere lieber seinen Ordner (Schritt 1) an dieselbe Stelle auf dem anderen PC.

4Aus einem anderen Emulator übernehmen

  1. Schließe den anderen Emulator (Eden, Lichii…).
  2. Beim ersten Start bietet Erable an, sein Profil zu importieren: wähle es und behalte Copy, das das Original unverändert lässt.
  3. Sonst kopiere den Ordner des Spiels von Hand aus dem Ordner nand\user\save des anderen Emulators in den von Erable (Schritt 1).
